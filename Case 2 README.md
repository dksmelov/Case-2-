# Кейс-задача. Базовый и производный классы## УсловиеНаписать тестовую программу, которая демонстрирует работу методовбазового и производного классов.## РешениеБазовый класс `Animal` содержит поле `name` и два метода:- `eat()` — обычный метод, наследуется как есть;- `speak()` — метод, который переопределяется в потомках.Производные классы `Dog` и `Cat` переопределяют `speak()`, а `Dog`добавляет собственный метод `fetch()`.В `main` демонстрируются:- вызов методов через сами объекты;- полиморфизм: вызов переопределённых методов через ссылку  на базовый класс.## ЗапускТребуется Python 3.6+:python main.pyclass Animal:                     # базовый класс    def __init__(self, name):        self.name = name    def eat(self):                # обычный метод        print(f"{self.name} ест.")    def speak(self):              # метод, который переопределят потомки        print(f"{self.name} издаёт звук.")class Dog(Animal):                # производный класс    def speak(self):              # переопределение        print(f"{self.name} говорит: Гав-гав!")    def fetch(self):              # собственный метод        print(f"{self.name} приносит палку.")class Cat(Animal):    def speak(self):        print(f"{self.name} говорит: Мяу!")if __name__ == "__main__":    d, c = Dog("Шарик"), Cat("Мурка")    d.eat(); d.speak(); d.fetch()    c.eat(); c.speak()    print("\nПолиморфизм:")    for a in (d, c):        a.speak()        a.eat()## Вывод программы    Шарик ест.    Шарик говорит: Гав-гав!    Шарик приносит палку.    Мурка ест.    Мурка говорит: Мяу!    Полиморфизм:    Шарик говорит: Гав-гав!    Шарик ест.    Мурка говорит: Мяу!    Мурка ест.## Проверка работы| Объект       | Унаследованный метод | Переопределённый метод | Собственный метод ||--------------|----------------------|------------------------|-------------------|| `Dog` Шарик  | `eat()`              | `speak()`              | `fetch()`         || `Cat` Мурка  | `eat()`              | `speak()`              | —                 |## Автор[Смелов С.В./ОБПз-42505ПДиибд]
